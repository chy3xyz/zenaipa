## 数据精度问题

### ⚠️ 需要修正

**问题**: 文档中声称"金额使用 INTEGER 存储美分"，但：

1. **代币数量**: 18 位小数精度，不能用 INTEGER 美分
2. **比率**: 千分比表示 (0-1000)，已正确
3. **市值**: 使用 BIGINT 美分，可能溢出大市值项目
4. **供应量**: 使用 String 存储，正确

**建议**: 
- 代币数量: String 或 NUMERIC
- 金额: BIGINT 最小单位（如 wei）
- 比率: INTEGER 千分比
